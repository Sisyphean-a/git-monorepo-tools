# 工作区上下文

- scope: workspace

## 术语

- **仓库快照**：某一时刻用于界面展示的仓库状态、文件变更和远端关系；不包含提交历史、提交详情或文件差异正文。
- **已忽略项目**：用户在本地设置中指定、不纳入仓库发现和扫描的仓库路径；可从设置中恢复监控。
- **交互操作**：用户发起并需立即反馈的单仓 Git 操作，如暂存、取消暂存、提交、拉取、推送和单仓刷新。
- **后台刷新**：启动扫描、自动扫描或全局手动刷新触发的非交互式状态读取。
- **按需详情**：用户进入历史、日志、文件浏览或文件差异界面后才读取的数据。
- **仓库文件浏览**：只读查看当前选中仓库工作树中的目录结构、文本文件正文及其高亮/Markdown 预览，不提供编辑或差异比较。
- **差异来源**：一次差异阅读所绑定的数据范围，取值为当前仓库的暂存变更、未暂存变更或某次历史提交差异；一个阅读会话只绑定一种来源。
- **暂存变更**：当前仓库 Git index 中已暂存、待提交的变更。
- **未暂存变更**：当前工作树相对 Git index 的变更；“变更区”在差异查看器语境中指此来源。
- **统一差异查看器**：应用内用于连续阅读一个差异来源的窗口，同时支持快速浏览和个人审查辅助，不承担评论、审批或协作审查。

## 稳定规则

- 交互操作按前台顺序执行，并以返回的单仓快照回写；后台刷新独立排队。侧栏手动扫描必须重新发现扫描根目录下的仓库，并以完整仓库快照更新界面；不得只刷新已存在的仓库。完整快照决定仓库列表组成（新增、移除、忽略、恢复），即使读取跨越了交互操作也必须应用；快照读取期间被交互更新的仓库保留本地结果，其余字段以快照为准。早期后台单仓结果不得覆盖交互结果。单仓更新不改变工作区扫描时间。
- 设置变更（添加或移除扫描目录、忽略或恢复仓库、保存设置）只做本地仓库发现刷新，不访问远端；远端状态由后台轮询、自动扫描和手动扫描负责。渐进启动扫描结束或被中断后，后台轮询必须接管仍处于“检查中”的仓库；自动扫描关闭时对其执行一次性补齐，避免仓库永久停在检查状态。
- 已忽略项目路径保存在本地设置中。启动、自动和手动扫描，以及批量操作的仓库发现都必须跳过这些路径；恢复监控后才可再次出现在仓库列表中。
- 组合操作在启动时绑定目标仓库，并按保存顺序完整执行；切换当前项目只停止旧项目的界面同步，不得取消、跳过或改向组合中的后续操作。
- 提交历史、提交详情、仓库文件树、文件正文和文件差异必须按需读取，不塞进基础仓库快照；历史页读取全部引用可达的提交，保留父提交哈希以渲染分支拓扑，并继续按页加载。
- 仓库文件浏览是独立的只读入口，位于主区域“历史”之后、“终端”之前：文件树直接展示仓库根目录的子项，不重复展示仓库根节点；目录展开时按需读取一级子项，折叠时释放该子树缓存；点击文件或切回仓库恢复阅读位置时才读取正文。切换仓库只保留各仓库的选中文件、展开目录、树与正文滚动位置、预览模式和换行偏好，不保留其他仓库正文；当前 Tab 重新激活或窗口重获焦点时更新已展开目录并检查当前文件版本，活跃且聚焦期间每 3 秒只检查当前文件元数据，版本变化才重读正文，不随后台仓库快照轮询重读文件。`.git` 和符合 Git 忽略规则的项不出现在树中，二进制文件和超过 1 MiB 的文件不加载正文并明确提示，所有请求路径必须保持在当前仓库内。文件树图标按文件类型区分。
- 文件预览在纯文本之上增加只读展示：已知扩展名按对应语言高亮，Markdown 默认渲染预览并在“预览/原文”之间切换；正文默认自动换行，可关闭以查看横向滚动，横向滚动条需清晰且可拖动。高亮与渲染只作用于当前文件，超过 256 KiB 的文件只显示纯文本并提示；渲染失败时保留已读到的纯文本并提示失败，不得把渲染失败显示为读取失败。高亮与 Markdown 渲染器按需加载，只有打开代码或 Markdown 文件时才取用。当前文件查找从预览右上角入口或 `Ctrl/Cmd+F` 打开，支持大小写、全字、正则、结果计数和循环切换上下项；它只查找已加载的当前正文，不触发仓库级搜索，查找时以原文定位匹配，关闭后恢复原有高亮或 Markdown 视图。
- Markdown 预览不执行仓库内容里的 HTML（原始标签按文本显示），只允许 http/https/mailto 外链、仓库内路径与安全的文档章节锚点。外链交给系统默认浏览器，相对或根路径链接解析到当前文件所在目录或仓库根，并在文件树中展开并打开目标文件；同文件和跨文件的 `#章节` 跳至目标标题，找不到标题时给出提示；越出仓库的路径、仓库内图片与不安全协议一律不打开。
- 统一差异查看器只作用于当前选中仓库，并且一次只绑定一个差异来源：暂存变更、未暂存变更或历史提交差异。工作区暂存和未暂存同时存在时默认未暂存变更；仅存在一种时默认该来源；不查看未跟踪文件或分支之间的差异。历史普通提交与其父提交比较，合并提交与第一父提交比较，根提交与空树比较。
- 统一差异查看器的入口位于当前仓库头部的外部终端按钮旁，弹窗属于应用内部且与外部终端无关；历史提交可通过独立入口进入同一查看器。弹窗每次打开均重新读取当前 Git 状态，不保留上次选择、滚动、展开或审查进度；文件清单完整可导航，差异正文按当前文件按需读取并在切换或关闭后释放，不保留跨文件缓存。左右代码列固定各占 50%，两列纵向滚动联动、横向滚动独立；正文隐藏 Git 文件头、索引和 hunk 标题，只展示代码行，长行自动换行并按实际渲染高度校准虚拟行位移，保证长差异可连续阅读且不重叠。个人审查标记仅存在当前会话，不提供评论、审批或协作。
- 所有未跟踪变更按文件展示：使用 `git status --porcelain=v1 -b --untracked-files=all`，每个未跟踪文件对应一个 `FileChange`，计数和列表使用同一粒度。
- 未跟踪文件不设静默数量上限；大仓库性能问题应优化读取或交互，不得遗漏真实变更。
- Pull 前必须显式拒绝扫描失败、有冲突或有本地变更的仓库；默认策略为 `--ff-only`，不会自动 merge、rebase 或 stash。
- 用户收藏的仓库 ID 保存在本地设置中，并按收藏顺序排列。侧栏仅在当前扫描结果包含至少一个收藏仓库时展示“收藏”分组；收藏仓库只显示在“收藏”分组，不得同时显示在原有分类。应用启动时，当前扫描结果中的第一项收藏仓库为默认打开项目；没有可用收藏时沿用原有默认选择。
