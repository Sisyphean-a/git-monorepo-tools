# 2026-11

- 2026-11-26 · [缺陷] Docker 页签按容器的实际平台校验镜像，消除成功更新后的旧镜像误报。范围：workspace
  原因：Docker 的镜像标签可指向 OCI 索引，容器返回的是运行镜像配置 ID，两者不同不能证明仍是旧镜像。
  当前依据：[Wails 桥接](../architecture/shared/wails-bridge.md)；`TestDockerProjectComparesTheRunningPlatformOfAnImageIndex`。

- 2026-11-26 · [功能] 为检测到 Docker 配置的仓库提供本地镜像构建、Compose 启停、代码更新和状态诊断。范围：workspace
  原因：单纯重启容器不会加载新构建的代码；仓库级入口需要区分环境、镜像和容器，并避免把同名 Compose 项目误当作当前仓库。
  当前依据：[工作区规则](../requirements/CONTEXT.md)、[Wails 桥接](../architecture/shared/wails-bridge.md)。

- 2026-11-12 · [功能] 终端 tab 栏取消固定的不可关闭页签：存在多个终端时所有终端都可关闭，只剩一个时不显示关闭入口；关闭当前终端后激活左侧最近终端。范围：workspace
  原因：固定“终端”页签永远不可关闭，无法按关闭页签的习惯整理终端；关闭后固定回到第一个终端也不符合关闭页签的预期。
  当前依据：[终端运行时契约](../architecture/shared/terminal-runtime.md)、[主区域 tab 定义](../requirements/CONTEXT.md)。
  证据：`src/app/components/workspace-terminal-tab.test.tsx`（唯一终端无关闭入口）、`src/app/features/terminal/terminal-workspace-tabs.test.ts`（tab 顺序与邻居选择）。
