- 2026-07-10 · [重构] Git 状态读取拆为交互、后台刷新和按需详情，避免慢刷新阻塞操作或旧结果覆盖新结果。范围：workspace

- 2026-07-24 · [演进] Windows 终端先原生检查剪贴板图片格式，仅有图片时才以隐藏 PowerShell 落为 `pi-clipboard-*.png` 临时路径并发送给会话，同时显式转发 Pi 的粘贴和多行输入协议。范围：workspace
  原因：Wails 运行时只提供文本剪贴板，xterm 不能自行把图片交给终端内的 Pi，且纯文本粘贴不应启动辅助进程或出现控制台闪窗。
  当前依据：`architecture/shared/terminal-runtime.md`、`architecture/shared/wails-bridge.md`。
  证据：`internal/desktop/clipboard_windows.go`、`src/app/components/repo-terminal-shortcuts.ts`。

- 2026-07-24 · [功能] 终端栏可新建和关闭独立会话，设置可收藏仓库并在侧栏展示收藏分组。范围：workspace
  原因：同一仓库的并行工作需要彼此独立的终端，而跨分类查找常用仓库成本高。
  当前依据：`architecture/shared/terminal-runtime.md`、`architecture/shared/wails-bridge.md`、`requirements/CONTEXT.md`。
  证据：`internal/terminal/manager.go`、`src/app/components/workspace.tsx`、`src/app/components/sidebar-repo-list.tsx`。

- 2026-07-24 · [缺陷] 关闭独立终端后不再把尚未完全退出的会话复用给默认终端。范围：workspace
  原因：关闭异步发生时，默认终端可能在旧会话退出前取回它，随后收到退出事件并显示为异常退出。
  当前依据：`architecture/shared/terminal-runtime.md`。
  证据：`internal/terminal/manager.go`、`internal/terminal/manager_windows_test.go`。
