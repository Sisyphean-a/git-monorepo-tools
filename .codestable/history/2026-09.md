- 2026-09-22 · [重构] 仓库文件树的 Git 忽略判断改为复用当前仓库唯一的 `git check-ignore --stdin` 会话，并在忽略规则、索引或仓库切换后重建，应用关闭时回收。范围：workspace
  原因：逐次展开目录都启动 Git 进程时，中位忽略检查约 85 ms，Windows 环境还会周期性出现 3.2–3.7 秒进程启动尖峰；会话复用后重复检查平均约 0.31 ms，包含目录读取与 129 个候选项过滤的基准约 2.1–3.9 ms/op。会话只缓存规则判定，忽略规则文件、`.git/index` 或仓库配置变化时重建，保证编辑 `.gitignore` 或被 `-f` 纳入版本控制的文件不会停留在过期结果。
  当前依据：`architecture/shared/wails-bridge.md`。
  证据：`snapshot/repo_ignore_session.go`、`snapshot/repo_files.go`、`snapshot/repo_files_test.go`、`snapshot/service.go`、`app.go`。
