- 2026-08-12 · [缺陷] 文件差异读取复用列表快照中的状态和未跟踪标记，普通点击从“再次扫描文件状态再读取差异”缩减为一次定向 Git 差异命令。范围：workspace

- 2026-08-12 · [缺陷] 周期 Git 状态刷新不再按扫描时间重挂已展开的文件差异，也不会因等价 `FileChange` 对象替换而取消尚未完成的读取；加载器跨同仓库快照复用，并只在文件可观察变更摘要变化时失效缓存。范围：workspace
  原因：高频快照每次都会替换 `RepoDetail` 和 `FileChange` 对象且改变扫描时间，原实现因此丢弃缓存、反复清理读取 effect，并重置差异滚动位置，导致慢请求可能长期停在加载状态且打断阅读。
  当前依据：`.codestable/architecture/INDEX.md`。
  证据：`src/app/components/workspace.tsx`、`src/app/components/diff-list.tsx`、`src/app/components/file-diff.tsx`、`src/app/features/diff/file-diff-loader.ts`。
